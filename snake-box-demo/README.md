# 蛇箱 · 八关试炼

无需构建、无需联网资源的 Emoji 解谜游戏。原六关保留，追加两关多机制挑战。

## 启动

```powershell
python .\snake-box\deploy.py
```

也可进入本目录运行 `python deploy.py`；自动选择本地端口并打开浏览器，Ctrl+C 停止。

直接双击 `snake-box-demo.html` 也可游玩。请保持 `levels.js` 与 HTML 在同一文件夹；分享时至少一起复制这两个文件。

## 关卡

| 关 | 名称 | 主要内容 |
|---|---|---|
| 1 | 热身 | 移动与推箱 |
| 2 | 推箱开路 | 推出缺口后绕行 |
| 3 | 吞食与生长 | 顶死箱链、吞食和增长 |
| 4 | 折门换边 | 弯蛇推尾蛇行、换侧整体平移 |
| 5 | 回环断尾 | 自咬、掉落尾箱再推动 |
| 6 | 双蛇换轨 | 两条弯蛇、传力、切断与出口箱 |
| 7 | 热炉接力 | 双蛇传力、NPC喂食、反推生长、尾箱跨蛇再利用 |
| 8 | 回流熔炉 | 自咬尾箱喂NPC、NPC返咬玩家、侧向和头端顶箱生长 |

逐步示范的已验证路线分别为 **5 / 7 / 8 / 19 / 36 / 28 / 44 / 42 步**。这是展示组合机制的路线，不宣称最短或唯一解。出口始终只检查玩家头的位置，没有机制计数锁。

第7关另发现利用头头转向的15步机制旁路；第8关将出口移至NPC初始头位，修复了旧草案绕过主要区域直接通关的路径。没有穷举证明所有机制都为任何解法所必需。

## 操作

- 方向键 / WASD 移动；Z / U 撤销；R 重开。
- 1–8 选关；过关后 Enter 下一关。
- 手机可用触屏方向按钮。
- 提示按钮逐条揭示；「主题攻略 / 逐步示范」可重开本关并逐步执行。
- 🟢/🟩 是玩家；🟠/🟨 是其他蛇箱；尾端有标记，箭头显示存储方向。

## 关卡数据

全部地图、NPC初态、渐进提示、攻略与验证事件都在 `levels.js`，修改后刷新。

- 地图各行等宽；坐标从左上 `(0,0)` 开始。
- `#` 墙，`.` 地板，`@` 单个玩家头，`> ^ < v` 指定初始面向，`B` 箱，`X` 出口，`*` 箱压出口。
- `snakes[].segments` 按头→尾排列，每节四邻接；`dir` 为头朝向。
- `solution` 是 U/R/D/L 操作序列；`expected` 与 `verification` 仅用于测试，不改变游戏目标。
- `mechanics` 是界面显示的组合机制标签。


第7关44步、第8关42步真实引擎攻略全部可执行并通关。**34/34 主测试通过**，含八关解法、撤销重放、事件身份、实体质量守恒和3200次固定种子随机输入。原六关数据与纯引擎段哈希保持不变。

## 文件说明

- `snake-box-demo.html`：页面和引擎。
- `levels.js`：八关运行数据。
- `deploy.py`：标准库本地部署脚本。
- `test-engine.js`、`tests/`：回归、可解性和机制覆盖验证。
- `ADVANCED_LEVEL_NOTES.md`：第7、8关接手记录。
- `DESIGN_NOTES.md`、`EXPANSION_NOTES.md`：规则及前六关历史记录。
- `experiments/`：设计候选与复现脚本，不参与游戏运行；候选可能是未完成或历史版本，正式数据以 `levels.js` 为准。

入口载体数据接口保留；双头蛇、跨关入口跳转和关卡编辑器不在当前范围。
