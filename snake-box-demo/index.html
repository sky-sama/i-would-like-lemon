    蛇箱规则速查

    非玩家蛇箱不会自行行动。从尾巴指向外侧的位置向内推，它按头的箭头蛇行；其他位置推动时，整条蛇作为异形箱平移。普通箱子也能传递推动。

    能推先推，推不动的箱子或身体才会被蛇头吃掉。蛇头不能吃蛇头。自咬按身体本步移位后的棋盘判定；被咬点之后没有头的身体变回普通箱子。红温属于各自蛇头，每吃一次入队一次。

    生长顺序：尾前空 → 头前空 → 尾前可推 → 尾侧空 → 头前可推 → 头侧空 → 尾侧可推 → 头侧可推。可推先试推出障碍，失败再试反向推自己；失败的红温保留，但不会挡住其他蛇头的生长。

    失败移动回滚整个试探。Z 撤销包含其他蛇的位置、方向、被吞箱和红温队列；自己的下一节所在方向不能原地掉头。可以从空出来的旧尾格走入。
